### 📝 자세한 변경 사항

**새 콘텐츠**
- 영웅 12명: 기존 5종 + 로그·성직자(치유 전담)·흙마법사·암흑마법사·방패병·기병·대포병
- 적 10종: 해골 전사·버섯 몬스터·유령 추가, 10스테이지 보스 **레드 드래곤**
- **월드 2 '모래 사막'** (11~20스테이지, 적 1.5~2.4배)
- **♾️ 무한 모드**: 20초마다 강해지는 웨이브, 명예의 전당(최고 기록 5개)

**전투**
- **특수 무기 9종** — 게이지가 차면 발사(메테오·화살비·번개·치유·충격파·빙결·수호·광폭·저격)
- **유닛 강화 스킬** — 강화 Lv1부터 영웅마다 고유 스킬 자동 발동
- **조합 보너스 7종** — 함께 출전하면 능력치 상승(예: 기사+방패병 '철벽 수비')
- 엘리트 적, 특수 웨이브(박쥐 떼·늑대 무리 등), 보스 패턴(골렘 땅 내려치기·드래곤 화염 숨결)
- 치명타·피해 숫자, 보스 처치 슬로모션, **배속 ×2**
- 레벨업 '보급'(최대 인구 증가)을 계속 선택 가능

**성장·보상**
- 유닛·특수 무기 **구매** 방식(병사·메테오 기본 지급)
- 특수 무기 영구 강화(위력·충전 시간·지속 시간)
- **⭐ 별 3개 평가** + 새 별 보너스 골드
- **📋 일일 미션 3개 + 업적 8개**
- **👗 스킨**: 레어 12종(500골드) · 전설 12종(1,500골드)

**화면·사운드**
- 시작·스테이지 선택·결과·보상 화면 리뉴얼(하늘·구름·풀밭, 둥근 버튼)
- 캐릭터 애니메이션·얼굴 아이콘·스킬 이펙트, 타워 파손 단계
- 효과음·배경음 추가(소리 켜기/끄기 저장)

**버그 수정**
- 방치 보상이 전투에 들어가면 사라지던 문제
- 일일 출석이 오전 9시에 초기화되던 문제(→ 자정)
- 출석 '연속 0일' 표시 오류
- 부활 후 에너지가 최대치를 넘던 문제
- 2스테이지 이후 다음 스테이지가 열리지 않던 문제
