■ 다시 만들 효과 5종 (보스 스킬)
roots(뿌리 묶기) · poison(독 숨결) · raise(해골 부활) · shards(수정 파편) · shadow(암흑 장막)

■ 1차에서 고칠 점 (게임 화면·휴대폰 기준)
- 너무 작고 흐려서 휴대폰(게임 화면이 약 0.7배로 줄어듦)에서 무엇인지 알아보기 어려움
- poison과 shadow가 색만 다른 같은 모양의 둥근 덩어리 → 서로 전혀 다른 모양이어야 함
- roots는 막대기 같고 5번째 프레임 이후 움직임이 없음
- raise의 손이 포크·촛불처럼 보임, shards는 가늘고 희미해서 거의 안 보임
- 어두운 전투 배경 위에서 묻힘(특히 그림자 숲 배경 #0c0c18, 수정 동굴 배경 #1a1430)

■ 규격 (1차와 동일 — 반드시 지키기)
- 투명 RGBA PNG, 프레임 384×192px, 6열×2행 = 12프레임, 시트 2304×384px, 왼쪽→오른쪽·위→아래 순서
- 첫 프레임(0)과 마지막 프레임(11)은 완전히 투명, 이웃 프레임 칸으로 픽셀이 넘치지 않기
- 기준점(pivot) x=340, y=160 = 보스 발밑. 효과는 기준점에서 왼쪽(아군 쪽)으로 펼쳐짐
- 땅 높이 = y 160. 땅에서 솟는 효과는 y 160에 붙어 있어야 함(공중에 뜨지 않기)
- 쓸 수 있는 범위: x 16~360, y 8~184 (게임에서 1.15~1.8배로 늘려 그림)
- 픽셀아트, 최근접 보간 기준(흐림·안티앨리어싱 번짐 없이), 게임의 귀여운 치비 픽셀 캐릭터와 어울리는 화풍
- 모든 덩어리에 어두운 외곽선(1~2px) + 밝은 속 하이라이트 → 어두운 배경·밝은 배경 모두에서 또렷하게
- 효과음: 효과마다 WAV 1개, 44,100Hz·모노·16-bit PCM, 피크 약 -3.35 dBFS, 시각효과 길이 + 0.15초 감쇠, 직접 합성(외부 샘플 금지)
- 파일 이름: export/sprites/Fx_<key>.png, export/audio/Sfx_<key>.wav, export/manifest.json(1차와 같은 항목: frameWidth·frameHeight·frames·fps·duration·pivot·facing·volume·concurrency·cooldownMs)
- 재생 시간 1.0~1.4초(fps 8.5~12)

■ 효과별 디자인
1) roots — 고대 나무 거인(숲 월드 보스). 맞은 아군은 2초 묶임.
   땅이 갈라지며 굵은 갈색 뿌리 4~5가닥이 왼쪽으로 차례차례(파도처럼) 솟아 오름 → 끝이 고리처럼 휘감김 → 잎·흙 조각이 튐 → 땅속으로 쑥 들어감.
   뿌리는 굵고 둥근 덩굴(두께 12px 이상), 밝은 녹색 잎·연두 하이라이트, 솟는 자리마다 흙먼지. 모든 프레임에서 움직임이 있어야 함.
   소리: 흙이 갈라지는 둔탁한 소리 + 나무가 삐걱이며 조이는 소리.

2) poison — 늪 히드라(독 늪 월드 보스). 맞은 아군은 4초 동안 독 피해.
   보스 입 높이(y 80~110)에서 독 액체 줄기가 왼쪽으로 뿜어져 → 바닥에 떨어져 독 웅덩이가 넓게 퍼짐 → 웅덩이에서 동그란 거품이 보글보글 올라와 톡 터짐.
   형광 연두·라임(#8aff5a 계열) + 진한 보라 외곽선, 거품 안에 흰 반짝임, 작은 해골 모양 거품 1~2개. '구름 덩어리'가 아니라 '액체·웅덩이·거품'으로.
   소리: 칙— 뿜는 소리 + 보글보글 + 치익 녹는 소리.

3) raise — 리치 왕(묘지 월드 보스). 기술을 쓰면 해골 병사 4마리가 보스 앞(왼쪽 60~180px)에 소환됨.
   바닥에 청록 마법진(룬 원)이 그려짐 → 마법진 위로 녹색 영혼 불꽃이 솟음 → 땅에서 뼈 손 3~4개가 쑥 올라와 손가락을 쫙 폄 → 영혼 불꽃이 위로 흩어짐.
   뼈 손은 손바닥·손가락 5개가 분명히 보이게 크게(높이 40px 이상), 상아색 + 회색 외곽선. 효과의 중심은 x 160~280(소환 위치).
   소리: 낮은 주문 웅웅 소리 + 뼈 달그락 + 유령 바람.

4) shards — 수정 골렘(수정 동굴 월드 보스). 가장 센 공격(사거리가 가장 김).
   보스 앞에서부터 왼쪽 끝까지 땅에서 보라·하늘색 수정 기둥이 차례로 날카롭게 솟음(높이 30→60px로 점점 크게) → 빛이 번쩍 → 기둥이 산산조각 나며 파편이 사방으로 튐.
   수정은 면이 나뉜 각진 결정(밝은 면 #e8f6ff, 중간 #a08aff, 어두운 면 #4a3a9a), 흰 반짝임 별. 범위 전체(x 16~340)를 덮어야 함.
   소리: 유리가 솟는 쨍 소리 연속 + 마지막에 와장창.

5) shadow — 그림자 군주(그림자 숲 월드 보스). 맞은 아군은 공격력이 조금씩 약해짐.
   보스 발밑에서 검보라 그림자가 바닥을 타고 왼쪽으로 빠르게 번짐 → 그림자에서 손톱 같은 검은 촉수 3~4개가 솟아 할퀴듯 휘어짐 → 보라 눈 2쌍이 잠깐 깜빡 → 아래쪽 화살표(▼) 모양 약화 표시가 내려앉으며 사라짐.
   몸체는 #2a1440 계열이지만 테두리는 밝은 보라·자홍(#c87aff) 빛 테두리로 감싸서 아주 어두운 배경(#0c0c18)에서도 보이게. 둥근 연기 덩어리 금지.
   소리: 낮게 깔리는 우웅 + 속삭임 같은 바람 + 힘이 빠지는 하강음.
