## 3. 적용 제안 (우선순위)

### ① 특수 관문 3종 — "같은 전투의 반복"을 깸 ⭐ 최우선
월드마다 10관문 중 3곳을 규칙 관문으로(5·10 보스는 그대로):
- **3번째 = 🛒 호위**: 우리 짐마차가 천천히 적 성으로 이동. 마차가 도착하면 승리, 부서지면 패배. 적 성은 부술 필요 없음.
- **7번째 = 🏰 수성**: 정해진 시간(예: 90초) 동안 우리 성 지키기. 적 생산이 갈수록 빨라짐. 성 업그레이드가 빛나는 관문.
- **8번째 = 🏃 돌파**: 아군 N명을 적 성 뒤 결승선까지 보내면 승리. 빠른 유닛(기병·로그)이 주인공.
- 결과 화면·관문 선택에 규칙 아이콘 표시, 출전 준비 화면에서 규칙 설명.
- 작업: 중. 지금 구조(웨이브·성·유닛 이동)를 그대로 쓰고 승리·패배 조건만 바꿈.

### ② 영웅 장비 — 무기(액티브) 1칸 + 반지(패시브) 1칸
- **영웅 무기**: J 스킬(철퇴 던지기)을 바꿔 끼우는 형태. 예: 얼음 철퇴(감속), 번개 철퇴(연쇄), 치유 철퇴(오라 회복), 황금 철퇴(처치 골드↑).
- **반지**: 경험치·골드·마나 충전·영웅 체력·이동 속도 중 1개.
- 둘 다 **등급 1~5**가 있고 🎁 보물 상자에서 나오거나 조각으로 올림. 상자의 가치가 커지는 효과도 있음.
- 작업: 중~대(새 그림은 아이콘 정도, Codex 담당).

### ③ 오라 특수기 강화 — 영웅을 움직일 이유를 더 크게
- 지금은 오라가 유닛 스킬 주기를 조금 줄여 주는 정도. 팔라독처럼 **오라 안에서는 유닛 스킬 발동이 2배 + 스킬 위력 +30%**, 유닛 위에 작은 ✨ 표시.
- "영웅을 어디에 둘까"가 매 순간의 선택이 됨. 작업: 소.

### ④ 업적 확장 + 목표 시간
- 추가 업적: 유닛 하나 Lv20, 1분 안에 관문 클리어, 한 판 100킬, 한 판 레벨업 5번, 별 300개, 누적 골드 100만, 월드 보스 10종 처치.
- 관문마다 **목표 시간** 표시(지금은 최단 기록만). 목표 안에 깨면 보너스 골드.
- 작업: 소.

### ⑤ 설치물 카드(토템형)
- 덱에 넣는 새 카드 종류: 그 자리에 서서 60초 동안 공격하고 사라짐. 예: 🐔 알 대포(원거리), 🔥 화염 토템(근처 지속 피해), 🌿 회복 토템.
- 작업: 중(그림 3장, Codex 담당).

### ⑥ 넉다운 · 밀림 저항
- 강한 공격(기사 돌진·대포·보스 내려치기)에 확률로 **넉다운**(뒤로 튕기며 0.6초 멈춤). 방패병·거대 적은 '밀리지 않음'.
- 화면이 시원해지고 방패병의 역할이 분명해짐. 작업: 소~중.

### 나중에 (규모가 큼)
- **운명 모드**: 매번 무작위로 정해진 유닛·레벨·장비로 시작하는 도전. 오늘의 도전과 합칠 수 있음.
- **두 번째 주인공**: 같은 관문을 다른 영웅(예: 어둠의 기사)으로 다시 하는 캠페인. 콘텐츠 2배.
- **온라인 랭킹**: 무한 모드 기록 경쟁. 서버가 필요함.
- **이동 공성병기(목마)**: 천천히 전진하며 적 성을 때리는 특수 소환.

## 4. 참고 수치 (설계 감각용)
- 적 본진 체력은 1챕터 3,000 → 4챕터 끝 150,000(약 50배). 우리는 기지 체력 ×(1.4+0.12×월드)라 완만한 편이고, 대신 적 능력치 배율(×9.6)로 어렵게 만듦.
- 고급 유닛은 비용 200·쿨타임 45초처럼 **한 판에 몇 번 못 부르는 '결전 카드'**로 설계. 우리 대포병·기병 쿨타임을 늘리고 위력을 키우는 방향을 검토할 만함.
- 보스는 체력이 매우 크고 공격은 약한 '깎는 보스'(서큐버스 40만, 데스나이트 100만)도 섞음. 우리 보스는 모두 '때리는 보스'라 한두 마리는 '오래 버티는 보스'로 바꾸면 리듬이 생김.

## 7. 화면 이동(카메라 스크롤) 분석 (2026-10-23)

### 팔라독은 이렇게 함 (디컴파일 근거: `GameUILayer.ScrollXAuto` · `ScrollX` · `ccTouchesMoved/Ended`, `GameLayer.ScrollLayer`)
- **전장이 화면보다 넓음**: 화면 480px, 배경은 1024px 폭 3겹(`background_NN_a/b/c` — 멀수록 넓은 그림, `GameJumpBGLayer` 3개 = 겹마다 다른 속도로 움직이는 원근감 배경). 전장 끝 = `iScrollMax`.
- **자동 따라가기**: 매 프레임 카메라 x = 영웅 x − 화면폭/3 → **영웅을 화면 왼쪽 1/3에 둠**(앞쪽 2/3이 적 쪽 시야). 0 ~ (전장폭 − 화면폭) 사이로 고정.
- **손가락으로 둘러보기**: 전장을 끌면 그만큼 카메라가 움직임(`ScrollX`, 끈 거리 그대로). **손을 떼면 자동 따라가기를 멈춤**(`m_bAutoScrollPause = true`) — 본 곳을 계속 보여 줌.
- **영웅 이동은 화면 왼쪽 아래 ◀ ▶ 버튼**(누르고 있는 동안 이동). 그래서 '끌기 = 카메라'와 충돌하지 않음.
- 이동 중에도 버튼 위에서 손가락을 미끄러뜨리면 방향이 바로 바뀜.
- 레이더(`radar_point_animal`) — 전장 전체를 작게 보여 주는 표시가 있는 것으로 보임(그림 이름만 확인, 동작은 미확인).
- 미확인: 자동 따라가기를 다시 켜는 정확한 조건(영웅 이동 버튼을 누를 때로 추정).

### 우리 게임과 차이
- 우리는 전장 = 화면(1280px) 한 장. 양쪽 성이 늘 보여서 **한눈에 보이는 장점**, 대신 전장이 좁아 **유닛이 금방 부딪치고 영웅 이동 폭이 작음**.
- 우리는 **전장 끌기 = 영웅 이동**이라 팔라독처럼 끌기를 카메라에 쓰면 충돌함.

### 적용안
| 단계 | 내용 | 효과 | 작업 |
|---|---|---|---|
| 1 | **전장 1.6배(약 2050px) + 카메라가 영웅을 따라감**(영웅을 화면 왼쪽 1/3, 부드럽게 따라붙음). HUD·버튼은 화면에 고정(UI 전용 카메라) | 전장이 넓어져 전진·후퇴의 맛, 마차 호위·돌파가 '여정'이 됨 | 중~대 |
| 2 | **원근감 배경 3겹**(하늘·먼 산·가까운 언덕이 다른 속도로 이동) | 화면이 움직일 때 깊이감 | 소 |
| 3 | **전장 지도(레이더)** — 지금 맨 위 VS 막대를 전장 축소판으로 교체: 아군 파랑·적 빨강 점, 보스 👑, 영웅 노란 점, 지금 보이는 범위 네모. **지도를 누르거나 끌면 그곳을 봄** | 넓어진 전장도 한눈에 파악 | 중 |
| 4 | **둘러보기 후 자동 복귀** — 지도로 다른 곳을 보다가 3초 손을 떼거나 영웅을 움직이면 영웅에게 돌아옴, 화면 구석 **📍 영웅에게** 버튼 | 길을 잃지 않음 | 소 |
| 5 | **화면 밖 알림** — 성이 공격받거나 보스가 나오면 화면 가장자리에 ◀ 깜빡이는 화살표 + 지도에 빨간 점멸 | 화면 밖 위험을 놓치지 않음 | 소 |

- 조작은 지금처럼 **전장 끌기 = 영웅 이동** 유지(이미 익숙한 조작), 둘러보기는 **지도**로 → 충돌 없음.
- 밸런스 영향: 전장이 길어지면 판이 길어짐 → 유닛·적 이동 속도 ×1.3, 성 사거리·영웅 이동 범위·특수 관문 거리(마차·결승선)를 전장 폭에 맞춰 함께 조정. 1~3관문(첫 경험)은 전장을 화면 한 장으로 유지하는 것도 방법.
- 위험: 위치 계산이 화면 좌표(`pointer.x`)를 쓰는 곳 점검 필요(영웅 끌기·성 터치·튜토리얼 손가락). 오래된 휴대폰 성능은 배경 3겹·카메라 이동에도 문제없음(그리는 양 거의 같음).
