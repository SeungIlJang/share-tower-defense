## 3. 적용 제안 (우선순위)

### ① 특수 관문 3종 — "같은 전투의 반복"을 깸 ⭐ 최우선
월드마다 10관문 중 3곳을 규칙 관문으로(5·10 보스는 그대로):
- **3번째 = 🛒 호위**: 우리 짐마차가 천천히 적 성으로 이동. 마차가 도착하면 승리, 부서지면 패배. 적 성은 부술 필요 없음.
- **7번째 = 🏰 수성**: 정해진 시간(예: 90초) 동안 우리 성 지키기. 적 생산이 갈수록 빨라짐. 성 업그레이드가 빛나는 관문.
- **8번째 = 🏃 돌파**: 아군 N명을 적 성 뒤 결승선까지 보내면 승리. 빠른 유닛(기병·로그)이 주인공.
- 결과 화면·관문 선택에 규칙 아이콘 표시, 출전 준비 화면에서 규칙 설명.
- 작업: 중. 지금 구조(웨이브·성·유닛 이동)를 그대로 쓰고 승리·패배 조건만 바꿈.

### ② 영웅 장비 — 무기(액티브) 1칸 + 반지(패시브) 1칸
- **영웅 무기**: J 스킬(철퇴 던지기)을 바꿔 끼우는 형태. 예: 얼음 철퇴(감속), 번개 철퇴(연쇄), 치유 철퇴(오라 회복), 황금 철퇴(처치 골드↑).
- **반지**: 경험치·골드·마나 충전·영웅 체력·이동 속도 중 1개.
- 둘 다 **등급 1~5**가 있고 🎁 보물 상자에서 나오거나 조각으로 올림. 상자의 가치가 커지는 효과도 있음.
- 작업: 중~대(새 그림은 아이콘 정도, Codex 담당).

### ③ 오라 특수기 강화 — 영웅을 움직일 이유를 더 크게
- 지금은 오라가 유닛 스킬 주기를 조금 줄여 주는 정도. 팔라독처럼 **오라 안에서는 유닛 스킬 발동이 2배 + 스킬 위력 +30%**, 유닛 위에 작은 ✨ 표시.
- "영웅을 어디에 둘까"가 매 순간의 선택이 됨. 작업: 소.

### ④ 업적 확장 + 목표 시간
- 추가 업적: 유닛 하나 Lv20, 1분 안에 관문 클리어, 한 판 100킬, 한 판 레벨업 5번, 별 300개, 누적 골드 100만, 월드 보스 10종 처치.
- 관문마다 **목표 시간** 표시(지금은 최단 기록만). 목표 안에 깨면 보너스 골드.
- 작업: 소.

### ⑤ 설치물 카드(토템형)
- 덱에 넣는 새 카드 종류: 그 자리에 서서 60초 동안 공격하고 사라짐. 예: 🐔 알 대포(원거리), 🔥 화염 토템(근처 지속 피해), 🌿 회복 토템.
- 작업: 중(그림 3장, Codex 담당).

### ⑥ 넉다운 · 밀림 저항
- 강한 공격(기사 돌진·대포·보스 내려치기)에 확률로 **넉다운**(뒤로 튕기며 0.6초 멈춤). 방패병·거대 적은 '밀리지 않음'.
- 화면이 시원해지고 방패병의 역할이 분명해짐. 작업: 소~중.

### 나중에 (규모가 큼)
- **운명 모드**: 매번 무작위로 정해진 유닛·레벨·장비로 시작하는 도전. 오늘의 도전과 합칠 수 있음.
- **두 번째 주인공**: 같은 관문을 다른 영웅(예: 어둠의 기사)으로 다시 하는 캠페인. 콘텐츠 2배.
- **온라인 랭킹**: 무한 모드 기록 경쟁. 서버가 필요함.
- **이동 공성병기(목마)**: 천천히 전진하며 적 성을 때리는 특수 소환.

## 4. 참고 수치 (설계 감각용)
- 적 본진 체력은 1챕터 3,000 → 4챕터 끝 150,000(약 50배). 우리는 기지 체력 ×(1.4+0.12×월드)라 완만한 편이고, 대신 적 능력치 배율(×9.6)로 어렵게 만듦.
- 고급 유닛은 비용 200·쿨타임 45초처럼 **한 판에 몇 번 못 부르는 '결전 카드'**로 설계. 우리 대포병·기병 쿨타임을 늘리고 위력을 키우는 방향을 검토할 만함.
- 보스는 체력이 매우 크고 공격은 약한 '깎는 보스'(서큐버스 40만, 데스나이트 100만)도 섞음. 우리 보스는 모두 '때리는 보스'라 한두 마리는 '오래 버티는 보스'로 바꾸면 리듬이 생김.
