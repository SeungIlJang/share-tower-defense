# 팔라독 플레이 분석 — 재미 요소와 우리 게임에 가져올 점

> 2026-10-19, 웹 아카이브(와플래시)에서 1-01 스테이지를 직접 플레이(별 3개, 3분 19초 클리어)하고 정리.

## 1. 한눈에 보기

| 항목 | 팔라독 | 모두의 타워디펜스(현재) |
|---|---|---|
| 조작 | 영웅을 좌우로 직접 이동 + 유닛 소환 + 영웅 스킬 | 유닛 소환 + 특수 무기 |
| 핵심 재미 | 영웅 주변 **오라** 안의 유닛만 강해짐 → 위치 선정 | 유닛 조합·타이밍 소환 |
| 자원 | 🍖 식량(유닛) / 💧 마나(영웅 스킬) | ⚡ 에너지 + 🍖 인구 / 특수 무기 게이지 |
| 레벨업 | 무작위 3장, 오라 중심 스킬 | 무작위 3장, 등급·각성(최근 개편) |
| 화면 | 전장이 화면보다 넓고 카메라가 영웅을 따라감 | 전장 전체가 한 화면 |

## 2. 재미 요소 자세히

### ① 영웅을 직접 움직인다 (가장 큰 차이)
- 말 탄 영웅 '팔라독'을 A/D(◀▶)로 움직이고, 카메라가 영웅을 따라간다.
- 영웅 발밑의 **노란 오라 원** 안에 있는 아군만 강화(방어·광폭·특수기술 확률)를 받는다.
- 그래서 "앞으로 나가서 최전선에 오라를 씌울까, 뒤에서 안전하게 있을까"를 계속 고민하게 된다.
- 영웅도 적에게 직접 맞으므로(빨갛게 깜빡임) 긴장감이 있다.
- 영웅이 안 움직이면 전선이 거의 밀리지 않는다 → 플레이어가 계속 손을 쓰게 만드는 구조.

### ② 쓰임새가 나뉜 두 가지 자원
- 🍖 **식량**(최대 40): 유닛 소환용. 시간이 지나면 찬다.
- 💧 **마나**(최대 100): 영웅 스킬(J/K/L)용.
- 유닛 칸마다 **소환 후 재사용 대기시간**이 있어 싼 유닛만 연타할 수 없다.

### ③ 짧고 자주 쓰는 영웅 스킬
- J 철퇴는 마나 10, 대기시간이 짧아 1~2초마다 누를 수 있다.
- 우리 특수 무기는 "모았다가 한 방"이고, 팔라독은 "늘 누를 거리가 있음".

### ④ 오라 중심의 무작위 레벨업
- 레벨업마다 무작위 3장이 나왔다.
  - 방어 오라: 오라 안 유닛 방어력 증가
  - 기술 오라: 오라 안 유닛의 특수기술 발동 확률 증가
  - 광폭 오라: 오라 안 유닛이 체력 30% 이하일 때 강하게 공격
  - 경작: 식량 생산 증가
  - 기도: 마나 회복 증가
  - 미믹: 경험치 증가
  - 반지 숙련: 장착한 반지 등급만큼 레벨 추가
- 스킬마다 최대 레벨이 다르다(2, 5, 9, 20).
- 구조는 우리가 만든 것과 같지만, 팔라독은 스킬이 **영웅 위치와 연결**되어 있다.

### ⑤ 계속 하게 만드는 장치
- 적을 잡을 때마다 골드가 떨어지고 숫자가 계속 올라가서 기분이 좋다.
- 결과 화면: 별 3개 + 클리어 보너스 + **클리어 시간 기록("신기록!")**.
- 로딩 화면에서 다음에 얻을 유닛을 미리 보여 준다(예: "왕실 근위병 곰").
- 유닛 설명에 "오라 안에서 점프 돌격" 같은 오라 연계 특수기술이 적혀 있다.
- 상점, 반지 장비, 유닛별 공격력·속도·공격 간격 강화.

## 3. 우리 게임에 가져올 점 (우선순위)

| 순위 | 내용 | 난이도 | 기대 효과 |
|---|---|---|---|
| 1 | **유닛별 소환 대기시간** — 칸마다 짧은 쿨타임 | 쉬움 | 아무거나 연타 방지, 유닛 고르는 전략 |
| 2 | **클리어 시간 기록 + "신기록!"** — 결과 화면 | 쉬움 | 같은 스테이지를 다시 할 이유 |
| 3 | **다음 유닛 미리보기** — 결과·로딩 화면 | 쉬움 | 해금하고 싶은 동기 |
| 4 | **영웅 스킬 버튼** — 싸고 대기시간 짧은 스킬(J/K/L 같은) | 보통 | 늘 누를 거리 |
| 5 | **영웅 유닛 + 오라** — ◀▶로 이동, 주변 유닛 강화. 레벨업 스킬(빠른 공격·공격력·튼튼한 몸)을 "오라 안" 효과로 바꿀 수 있음 | 큼 | 팔라독 재미의 핵심, 위치 선정 전략 |

### 추천 진행 순서
1. 1·2·3번(작고 안전한 것) 먼저
2. 5번(영웅 + 오라)은 화면 구성·조작·밸런스가 크게 바뀌므로 따로 설계 후 진행
3. 4번은 영웅이 생기면 그 스킬로 붙이기
